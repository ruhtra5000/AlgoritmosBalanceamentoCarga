BALANCEAMENTO DE CARGA

Utilização do NGINX para realização de análise de desempenho de algoritmos de balanceamento distintos em servidores heterogeneos.

Ex.:

                     ┌── Server 1
                     │
Cliente → NGINX ─────┼── Server 2
                     │
                     └── Server 3

Testes:
- 1, 3, e 6 servidores;
- Algoritmos de balanceamento:
	- Round Robin (estático);
	- IP Hash (estático);
	- Menos conexões (dinâmico).
- Diferentes cargas:
	- 10.000 requisições
	- 100.000 requisições

Métricas:
- throughput;
- latência média;
- p50;
- p95;
- p99;
- taxa de erro;
- CPU;
- memória;
- distribuição das requisições.
